# Website Template Advanced

Bài CodeGym 1553.

## Chạy
Mở index.html trên trình duyệt.

## Nội dung
Header nền ảnh blur và overlay, menu cố định, 3 card Grid có hover, footer 2 cột, responsive. Ảnh mẫu từ https://www.w3schools.com/css/css_rwd_images.asp (các ảnh được cung cấp trong bài gallery trước).

## Kiểm tra
